# @loage/mcp

The [Loage](https://github.com/loage-ai/loage) MCP server. The `loage-mcp` command exposes the flows you list in `mcp.expose` as tools over stdio or Streamable HTTP. The package also provides the `mcp` node for calling other MCP servers.

```bash
npx @loage/mcp loage.config.yaml
```

See the [MCP guide](https://loage.mintlify.site/guides/mcp).
