# @milford/mcp

The [Milford](https://github.com/milfordai/milford) MCP server. The `milford-mcp` command exposes the flows you list in `mcp.expose` as tools over stdio or Streamable HTTP. The package also provides the `mcp` node for calling other MCP servers.

```bash
npx @milford/mcp milford.config.yaml
```

See the [MCP guide](https://milford.mintlify.site/guides/mcp).
