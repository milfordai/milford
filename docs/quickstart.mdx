## Prerequisites

- Node.js 22 or later, and pnpm.
- An API key for any supported provider. The example below uses Anthropic.

## Run the example

<Steps>
  <Step title="Build the workspace">
    ```bash
    pnpm install
    pnpm build
    ```
  </Step>
  <Step title="Set your keys">
    ```bash
    export LOAGE_TOKEN=change-me
    export ANTHROPIC_API_KEY=sk-ant-...
    ```
  </Step>
  <Step title="Start the server">
    ```bash
    node packages/server/dist/cli.js examples/flows/loage.config.yaml
    ```
  </Step>
  <Step title="Run a flow">
    ```bash
    curl -s localhost:8080/v1/flows/hello/run \
      -H "authorization: Bearer $LOAGE_TOKEN" \
      -d '{"input": {"name": "Ann"}}'
    ```
    The response contains the result of every node and the `output` of the flow.
  </Step>
</Steps>

## Use the library instead

```ts
import { createEngine, defaultRegistry, flow } from "@loage/core";
import { registerProviders } from "@loage/providers";

const engine = createEngine({
  registry: registerProviders(defaultRegistry()),
  providers: [{ id: "main", type: "anthropic", apiKey: process.env.ANTHROPIC_API_KEY!, model: "claude-sonnet-5" }],
  flows: [
    flow("summarize")
      .node("sum", "llm", { provider: "main", preset: "summarize", prompt: "{{input.text}}" })
      .node("out", "output")
      .edge("sum", "out")
      .build(),
  ],
});
if (!engine.ok) throw new Error(engine.error);

const result = await engine.value.run("summarize", { text: "..." });
```

`createEngine` and `run` return results instead of throwing. Check `ok` before you read `value`.
